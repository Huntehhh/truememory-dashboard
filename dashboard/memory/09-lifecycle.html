The three sleep behaviors

TrueMemory has three distinct paths that trigger the same ingest pipeline — only two of them have anything to do with session end.

trigger 1 of 3
on session end · synchronous

Stop Hook

You close the session. The harness fires a Stop event handler that validates the transcript, then spawns a detached subprocess to do the actual work. Returns in milliseconds — consolidation runs while you are away.

trigger 2 of 3
every 4 hours · silent

Incremental Extraction

A hook fires on every UserPromptSubmit and checks the mtime of ~/.truememory/last_incremental_extraction. If 4+ hours have elapsed, it triggers extraction mid-session — memories can land in the DB without you closing anything.

trigger 3 of 3
every 30–120 s · daemon

Backlog Drainer

A daemon thread inside the MCP server polls ~/.truememory/backlog/*.json every 30 seconds. Orphaned sessions — from crashes or kills mid-ingest — get re-spawned as new subprocesses. As long as the MCP server is alive, it is watching.

What the lifecycle does not do

The schema implies a richer story than the runtime delivers. These are the things that look like they happen — but do not.

consolidation
build_summaries() is never auto-called. Rollups into the summaries table only happen via manual engine.consolidate() or truememory_configure.
contradiction detection
detect_contradictions() is gated under consolidate(). The fact_timeline table stays empty in normal use.
episode assignment
The episode_id column exists on every row but is never written during ingestion. Episodes are detected during consolidate() only.
surprise scoring (native)
The surprise_scores table is built by build_surprise_index() during consolidate(). Empty in normal use. The observatory re-implements surprise at ingest.
landmark events
detect_landmark_events() pattern-matches messages against life-event regexes. Only runs under consolidate(). Table empty in normal use.
salience decay
There is no salience column on messages at all. Salience is computed by a pure function from content; the score is never stored, never modified, never aged.
